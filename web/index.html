Sharing

Some providers take reference images and videos only as links. Pragma puts each file in a bucket of your own, gives the provider a link that expires after a day, and deletes the file when the job ends.

Works with any S3-compatible storage. Saving puts a small file in the bucket, opens it by its link and deletes it, so a bucket that can't share files is never saved.
